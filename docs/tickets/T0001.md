# T0001

Title: Add GitHub CI for lint and production build
Domain: Platform
Epic: EPIC 00: Platform Governance and Baseline
Type: infra
Priority: P0
Estimated size: S
Owner type: platform
Problem: The repo has no automated merge gate for basic health.
Goal: Run `npm run lint` and `npm run build` on pull requests.
Scope: Add a GitHub Actions workflow and update the repo memory docs only if needed.
Allowed files:
- `.github/workflows/ci.yml`
- `package.json` only if absolutely needed
- `docs/Repo_Current_State.md`
- `docs/Known_Issues_And_Followups.md`
Do not touch:
- `src/`
- `prisma/`
- app features
- dependencies unless absolutely required for the workflow to function
Acceptance criteria:
- Pull requests trigger lint and build checks
- the workflow uses existing project commands only
- the repo docs record that the first GitHub-hosted run still needs verification until it actually executes
Manual verification:
- run `npm run lint` locally
- run `npm run build` locally
- review the workflow triggers, Node setup, and commands for correctness
- mark GitHub execution as `Needs verification` until the first real PR run completes
Commands to run:
```powershell
npm run lint
npm run build
```
Risks:
- temporary friction if CI exposes existing hidden issues
Dependencies:
- none
Rollback plan:
- disable or revert `.github/workflows/ci.yml` if it blocks urgent releases for non-product reasons
