Title: Add benchmark scripts for watchlists and movie detail
Domain: Platform
Epic: EPIC 00: Platform Governance and Baseline
Type: perf
Priority: P0
Estimated size: S
Owner type: backend
Problem: Timing logs alone are not enough; optimization work also needs repeatable local probes.
Goal: Add simple benchmark scripts that can exercise watchlist and movie-detail endpoints without making unverified performance claims.
Scope: Scripts and docs only. No performance refactors.
Allowed files:
- `scripts/benchmark-watchlists.mjs`
- `scripts/profile-movie-detail.mjs`
- `docs/performance/baseline.md`
- `docs/Manual_Verification_Guide.md`
- `docs/Known_Issues_And_Followups.md`
- `package.json` only if a script alias is absolutely needed
Do not touch:
- `src/app/(pages)/`
- feature logic under `src/app/libs/`
- `prisma/`
- dependencies
Acceptance criteria:
- both scripts run locally against a documented base URL or local dev server
- each script prints useful timing-oriented output or a clear setup failure message
- the docs explain prerequisites and clearly avoid claiming benchmark wins
Manual verification:
- run each script against the local environment
- confirm the output is understandable and non-empty
- if auth or data realism is missing, record that gap as `Needs verification`
Commands to run:
```powershell
node scripts/benchmark-watchlists.mjs
node scripts/profile-movie-detail.mjs
```
Risks:
- scripts may become too broad or too environment-specific
Dependencies:
- `T0002`
- `T0003`
Rollback plan:
- remove the scripts and keep only the documented measurement approach if they prove too noisy
